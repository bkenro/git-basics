# Git 入門講座：演習用ファイル

このリポジトリは、「[Git 入門講座](https://new.sqt.jp/product/10)」の実習や総合演習で使用するファイル一式を提供するものです。

| ファイル | 役割 |
|---|---|
| `RES-SITE.md` | 題材サイトの全ファイル内容（版 V1〜V7 と補助ファイル） |
| `RES-STEPS.md` | モジュール 3〜8 を貫く操作ステップ（STEP-001〜STEP-099）と単元対応表 |
| `reset-to.sh` | チェックポイント C1〜C7 の状態を再現するスクリプト |
| `capstone-task.md` | 総合演習の課題 |
| `capstone-solution.md` | 総合演習の解答例 |


## reset-to.sh

使用法：

```sh
./reset-to.sh <c1|c2|c3|c4|c5|c6|c7> [作業ディレクトリ]
```

既定の作業ディレクトリは `~/portfolio`。実行すると対象ディレクトリを**削除して**作り直すため、
確認プロンプトが出る。

C5 以降はリモートリポジトリを伴うが、GitHub は使わず**ローカルの bare リポジトリを
`origin` の代役**として作る。学習途中からの復帰用であり、モジュール 6 で学ぶ
GitHub との接続手順の代わりにはならない。
